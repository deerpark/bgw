# 부개원 한의원 — 컴플라이언스 & 카피 가이드

> 본 문서는 보건의료법·의료법·의료광고에 관한 자율심의 기준을 반영한 **카피 가드레일**과 **페이지별 카피 템플릿**이다.
> 모든 페이지 게시 전 §1 체크리스트를 통과해야 한다.

---

## 1. 의료광고 자율심의 핵심 체크리스트

> 한의사회 의료광고 자율심의에서 자주 지적되는 요소를 기반으로 정리. 본 항목은 **카피 작성·디자인 단계 전부에 적용**된다.

### 1.1 절대 금지

| # | 금지 사항 | 안 되는 예 | 비고 |
|---|---|---|---|
| 1 | 효과·치료기간·체중감량 수치 단정 보장 | "한 달 –10kg 보장", "100% 효과" | 추정·평균도 단정형 금지 |
| 2 | "최고 / 유일 / 1위 / 가장 우수 / 국내 최초" 등 비교·우월 표현 | "국내 최고의 다이어트 한약" | 객관 자료가 있어도 자율심의 권장 |
| 3 | 환자 후기·체험기 — 사진 포함, 효과 단정 묘사 | "10kg 빠졌어요!" 사진 | 텍스트 후기도 효과 단정형이면 위험 |
| 4 | Before/After 사진 (체형·얼굴) | 다이어트 전후 비교 사진 | 의료광고 심의 미통과 사용 불가 |
| 5 | 가격 할인·이벤트·"오늘만 30%" 류 | "이벤트가 한약 50%" | 가격 광고는 한정적으로만 |
| 6 | 의료기관·의료인 비방, 환자 유인 (소개비) | "타 한의원보다 저렴" | |
| 7 | 의료기관 평가 결과를 광고에 사용 | "전국 1위 한의원" | |
| 8 | 결제·배송 신청을 직접 받는 UI/카피 | "지금 구매하기 / 장바구니" | 보건의료법 — 비대면 진료 접수 형태로만 |

### 1.2 권장 표현으로 대체

| 금지/위험 | 권장 |
|---|---|
| 다이어트 한약 구매 / 주문 / 결제 | **비대면 진료 접수 / 비대면 진료 상담 신청** |
| 한약 처방받기 (사용자가 능동적 처방받기 표현) | **한의사 진료 후 처방** |
| 100% / 보장 / 무조건 | **체질에 맞춰 처방 / 개인차가 있을 수 있습니다** |
| 부작용 없음 / 안전한 한약 | **한의사가 체질·복약 이력을 살핀 뒤 처방하여 부작용 위험을 최소화합니다** |
| 빠르게 살이 빠집니다 | **체질·생활습관에 맞는 처방으로 무리 없는 다이어트를 돕습니다** |
| 인기 1위 / 베스트셀러 | (사용 금지) |
| 후기 5,000건 | (자율심의 미통과 시 금지, 단순 정보 통계는 신중) |

### 1.3 의무 표기 (모든 한약 상세 페이지)

페이지 하단 `<MedicalDisclaimer>` 컴포넌트를 통해 다음 문구를 항상 노출:

```
※ 본 한약은 한의사의 진료 후 체질·증상·복약 이력에 따라 개별 처방되며,
  개인에 따라 효과 및 반응은 다를 수 있습니다.
※ 임신·수유 중이거나, 만성 질환이 있는 경우 반드시 사전에 알려주시기 바랍니다.
※ 본 페이지는 의료광고 자율심의 기준을 준수하여 작성되었습니다.
```

### 2.6 한의원 소개 (`/clinic`) 원페이지

앵커 섹션: `#소개`, `#의료진`, `#내부`, `#오시는길`, `#진료시간`

- 의료진: 면허번호 표기, 학력·경력 사실 위주 (수상·1위 표현 금지).
- 내부 사진: 자체 촬영, 톤 보정 후 사용.
- 오시는길: 네이버 지도 임베드 + 주차 안내 + 대중교통.
- 진료시간 표:

```
평일      09:00 – 19:00
토요일    09:00 – 14:00
일요일·공휴일 휴진
점심시간  13:00 – 14:00
```

### 2.7 진료과목 표준

각 진료과목 페이지는 다음 6 섹션 구조:

1. Hero (eyebrow + 한 줄 본질)
2. 어떤 증상인가
3. 부개원의 접근 (한방 관점, 단정 표현 금지)
4. 진료 절차
5. FAQ
6. 예약·문의 CTA (전화 + 카카오)

자동차보험 페이지에는 추가로:
- 보험 적용 안내 (실손 보험사 협진)
- 필요 서류 (사고접수번호 등)
- 연락 시 전달할 정보 체크리스트

## 3. 카피 톤 매뉴얼

### 3.1 톤 키워드
- **차분 / 단정 / 신뢰 / 인간적인 친근함**

### 3.2 문체
- 본문은 **존댓말**, 그러나 무겁지 않게.
- "~합니다 / ~드립니다 / ~안내해 드립니다"
- 1인칭 ("저희") 보다는 한의원 명 ("부개원 한의원") 사용을 우선.
- 명령형 ("지금 신청하세요!") 자제 → 권유형 ("편하실 때 접수해 주세요").

### 3.3 마이크로카피 예시

| Spot | 권장 카피 |
|---|---|
| 버튼 (primary) | 비대면 진료 접수 |
| 버튼 (보조) | 카카오톡으로 문의하기 |
| 폼 제출 후 토스트 | 접수가 정상적으로 도착했어요. 곧 한의원에서 연락드립니다. |
| 폼 검증 에러 | 휴대폰 번호 형식을 다시 확인해 주세요. |
| 빈 상태 | 아직 등록된 글이 없어요. |
| 404 | 페이지를 찾을 수 없어요. 메인으로 돌아가시겠어요? |
| 로딩 (긴 작업) | 잠시만 기다려 주세요. 한의원이 정성껏 준비하고 있어요. |

## 4. 개인정보·동의

비대면 진료 접수 폼(네이버폼 또는 자체 폼)에는 다음 항목을 명시한다:

```
[수집 항목] 이름, 연락처, 성별, 나이, 신체 정보(키·체중), 건강 상태, 복약 이력, 임신·수유 여부
[수집 목적] 한의사 진료 및 한약 처방·조제·발송, 진료 결과 안내
[보유 기간] 의료법에 따른 진료기록 보존기간(10년)에 준함
[동의 거부 권리 및 불이익] 동의를 거부할 수 있으나, 거부 시 진료 불가
```

마케팅 수신 동의는 별도(체크 분리), 기본 미체크.

## 5. 개시 전 자체 점검 체크리스트

- [ ] 효능·효과 단정·보장형 표현이 없다
- [ ] 비교·우월·1위·최고 표현이 없다
- [ ] before/after 사진이 없다
