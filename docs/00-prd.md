# 부개원 한의원 — PRD (Product Requirements Document)

문서버전: 1.0 · 작성일: 2026-04-29 · 작성자: 주인 + AI 협업

## 1. 비전 한 줄

> 부개원 한의원의 다이어트·면역 한약을 **신뢰감 있게 알리고**, **방문 없이도 안전하게 진료받을 수 있도록** 환자를 비대면 채널로 매끄럽게 연결한다.

## 2. 비즈니스 목표

| 목표 | 측정 (KPI) | 6개월 타겟 |

## 3. 사용자·시장

### 3.1 페르소나
- **P1 — 30대 직장 여성 김다현**: 다이어트 시도 다회, 한약 처음. 후기와 부작용 설명을 꼼꼼히 본다.
- **P2 — 50대 여성 이순영**: 갱년기·기력 감소. "원장님이 어떤 분인가"가 결정 요인. 글씨 크고 단순한 UI 선호.
- **P3 — 40대 남성 박재훈**: 출장 잦아 방문 어려움. 신뢰 가능한 곳이면 비대면 처방을 적극 활용하고 싶다.
- **P4 — 운영자(원장 / 스태프)**: 외래 진료 사이사이 모바일로 접수 확인·통화·상태 변경.

### 3.2 경쟁/참조
- 경희바로한의원 (`khbaro.com`) — 다이어트 + 비대면 흐름 표본
- 다이어트한의원, 바로스탑, 채율, 해인부부 — 비대면 진료 + 택배 발송 표본

### 3.3 차별화 포인트
- 부개원 고유 라인업: 부개 감비환·감비탕·디톡스 (네임 자산화)
- 면역 한약(공진단·경옥고·녹용보약) 카테고리 동등 비중
- 한의원 + 비대면 + 자동차보험까지 정직하게 한 곳에서 (지역 의원 강점)

## 4. 범위

### 4.1 IN
- 한의원 공식 웹앱 (반응형, 한국어)
- 다이어트 한약 3종 / 면역 한약 3종 / 진료과목 5종 페이지
- 한의원 소개 원페이지 (소개·의료진·내부·길찾기·시간)
- 비대면 진료 접수 안내 페이지(네이버폼·카카오·전화 3채널)
- 관리자 모드 (접수 · 콘텐츠 · 제품 · 통계 · 설정)
- 외부 채널 연동 (네이버폼 webhook, 카카오 채널 딥링크, 네이버 플레이스 임베드, 네이버 블로그 RSS)

### 4.2 OUT (현 단계)
- 사이트 내 결제·장바구니 (보건의료법)
- 환자 자체 회원가입 (필요성 낮고 컴플라이언스 부담)
- 한약 직접 배송 트래킹(택배사 연동) — Phase 3 검토
- 다국어 (영어·중국어) — Phase 3

## 6. 비기능 요구사항

| 영역 | 요구사항 |
|---|---|
| 성능 | LCP < 2.5s (모바일 4G), CLS < 0.1, INP < 200ms |
| 접근성 | WCAG 2.1 AA, 키보드 only 사용 가능 |
| 반응형 | 360px ~ 1920px |
| 보안 | RLS 기본 deny, service-role 서버 전용, HTTPS only, 폼 CSRF 토큰 |
| 컴플라이언스 | 보건의료법·의료광고법, 개인정보 수집·이용 동의 절차 |
| 가용성 | 99.9% (Vercel + Supabase 가동률 의존) |
| 백업 | Supabase PITR (7일) — 운영 후 결정 |
| 브라우저 | 최신 Chrome/Safari/Edge/FF, iOS Safari 17+, Android Chrome 최신 |

## 7. 성공 지표 (Definition of Done)

### 7.1 출시(Phase 1) DoD
- [ ] 모든 P0 페이지가 라이트하우스 모바일 SEO/Best Practices/Accessibility ≥ 95
- [ ] 모든 한약 상세에 의무 고지 컴포넌트 노출
- [ ] 비대면 진료 CTA가 모바일/PC 어느 페이지에서도 1탭 안 도달
- [ ] 핵심 이벤트가 PostHog에 흐른다
- [ ] 컴플라이언스 카피 체크리스트 통과
- [ ] 운영자 메일에 네이버폼 응답이 정상 도착
- [ ] 도메인 + SSL + 사이트맵 제출 완료

### 7.2 Phase 2 DoD
- [ ] 운영자가 외부 도구 없이 접수→처방→발송 상태를 관리할 수 있다
- [ ] 관리자가 콘텐츠/배너를 코드 수정 없이 편집한다
- [ ] 접수 평균 처리 시간이 측정 가능하다

## 8. 가정 / 제약 / 리스크

| 구분 | 내용 | 대응 |
|---|---|---|
| 가정 | 네이버폼이 운영 표준 폼 도구 | 폼 변경 시 자체 폼 fallback 필요 |
| 가정 | 카카오 채널은 운영자가 1:1 응답 가능 | 자동응답 봇은 Phase 2 검토 |
| 제약 | 보건의료법 — 결제·배송 신청 UI 금지 | 카피·UI 가드레일 강제 |
| 제약 | 의료광고 자율심의 (한의사협회) | 게시 전 자체 체크 + 필요 시 심의 |
| 리스크 | before/after 사용 압박 | 정책 명시 + 텍스트 후기로 대체 |
| 리스크 | 네이버폼 데이터 적재 자동화 지연 | 초기엔 수기 입력 가능한 admin UI 우선 |
